\## Repository Overview



This repository includes scripts for:



\- Metagenomic and metatranscriptomic data analyses  

\- Multi-omics integration workflows  

\- Statistical analyses and visualization  

\- Figure generation for the manuscript  

\- Functional mapping and pathway-level analyses  



Due to file size limitations, large datasets and intermediate outputs are hosted externally (see Data Availability below).



\---



\## Data Availability



\### Sequencing Data



Raw metagenomic and metatranscriptomic sequencing data are publicly available through the NCBI BioProject database:



\- \*\*BioProject accession:\*\* PRJNA1193034  

\- NCBI BioProject: https://www.ncbi.nlm.nih.gov/bioproject/?term=PRJNA1193034



\### Processed Data and Supporting Files



Datasets generated during this study are available through the OSF repository:



\- OSF Repository: https://doi.org/10.17605/OSF.IO/UDGPY



The OSF repository includes:



1\. Raw untargeted liquid chromatography–mass spectrometry (LC–MS/MS) data and processing outputs generated using Compound Discoverer 3.3.2.31 (Thermo Fisher Scientific), including:

&#x20;  - feature detection and alignment outputs  

&#x20;  - exported feature tables  



2\. Curated and quality-filtered metabolomics datasets used for downstream analyses  



3\. KEGG-derived module and reaction definitions used for functional mapping of transcript reads, including:

&#x20;  - gene length–corrected trimmed mean of M-values (geTMM) transcript abundances  

&#x20;  - sample-level transcript datasets  

&#x20;  - MAG-resolved transcript datasets  



4\. Measurements of residual inorganic nitrogen pools:

&#x20;  - nitrate-nitrogen (NO₃⁻–N)  

&#x20;  - ammonium-nitrogen (NH₄⁺–N)  



5.MetaCyc pathway annotations



6.Eggnog annotations: Enzyme Commission (EC) numbers obtained from eggNOG v5 111 from annotations generated with eggNOG-mapper v 2.1.12.
