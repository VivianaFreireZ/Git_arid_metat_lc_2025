## Repository Overview

This repository includes scripts for:

- Metagenomic and metatranscriptomic data analyses  
- Multi-omics integration workflows  
- Statistical analyses and visualization  
- Figure generation for the manuscript  
- Functional mapping and pathway-level analyses  

Due to file size limitations, large datasets and intermediate outputs are hosted externally (see Data Availability below).
